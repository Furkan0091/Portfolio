What "understand the code" looks like

This is how I read a system — not the board, the mechanics. Gateways retry, so an event that already landed must never be applied twice. The endpoint below matches each incoming payment to an open invoice, and anything ambiguous goes to a human instead of being auto-applied.

// POST /webhooks/payments — replay-safe by design
router.post('/webhooks/payments', async (req, res) => {
  const { id: eventId, invoiceId, amount } = req.body;

  // A gateway can retry the same event — never apply it twice
  if (await db.processedEvent.exists(eventId)) {
    return res.status(200).json({ status: 'already_processed' });
  }

  // Match it to an open invoice, or park it for a human review
  const match = await reconcile.match({ invoiceId, amount });

  await db.$transaction([db.payment.create(match), db.processedEvent.record(eventId)]);
  return res.status(202).json({ status: match.confidence === 'high' ? 'matched' : 'needs_review' });
});
